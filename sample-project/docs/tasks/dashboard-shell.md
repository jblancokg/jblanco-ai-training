# Dashboard Shell

Core application structure: layout, navigation, dark mode, storage layer, and home page.

---

**Description**

Initialize the project using Vite with the React + TypeScript template. Install and configure all core dependencies: React 19, TanStack Router, Tailwind CSS v4, and shadcn/ui. Set up path aliases so imports use `@/` instead of relative paths.

**Acceptance Criteria**

- [ ] Project created with `pnpm create vite` using the React + TypeScript template
- [ ] React 19 installed and working
- [ ] TanStack Router installed with file-based routing configured
- [ ] Tailwind CSS v4 installed and imported in the app entry point
- [ ] shadcn/ui initialized with a few base components available (Button, Card, Dialog)
- [ ] Path alias `@/` mapped to `src/` in both `tsconfig.json` and `vite.config.ts`
- [ ] `pnpm dev` starts the dev server without errors
- [ ] `pnpm build` produces a clean production build
- [ ] Feature-based folder structure created: `src/features/`, `src/components/`, `src/hooks/`, `src/lib/`, `src/routes/`

**Files to Create or Modify**

- `package.json`
- `vite.config.ts`
- `tsconfig.json`
- `tailwind.config.ts`
- `src/main.tsx`
- `src/index.css`
- `src/routeTree.gen.ts` (auto-generated by TanStack Router)

**Dependencies**

None. This is the foundation task.

## Task 3: Implement Dark Mode Toggle

**Description**

Create a `useDarkMode` hook that reads the user's preference from localStorage, applies a `dark` class to the `<html>` element, and exposes a toggle function. Wire this into the header's toggle button. Use the storage wrapper from Task 4 for persistence.

**Acceptance Criteria**

- [ ] `useDarkMode` hook at `src/hooks/use-dark-mode.ts` returns `{ isDark, toggle }`
- [ ] On first visit, the hook respects `prefers-color-scheme` from the OS
- [ ] Toggling adds or removes the `dark` class on `document.documentElement`
- [ ] Preference persists in localStorage under a `dashboard-dark-mode` key using the storage wrapper
- [ ] Header toggle button shows a sun icon in dark mode and a moon icon in light mode
- [ ] No flash of wrong theme on page load (consider an inline script or early initialization)

**Files to Create or Modify**

- `src/hooks/use-dark-mode.ts`
- `src/components/Header.tsx` (update toggle button)

**Dependencies**

- Task 2 (header must exist)
- Task 4 (storage wrapper must be available)

**Estimated Scope:** Small (1hr)

## Task 4: Create localStorage Wrapper and useStorage Hook

**Description**

Build a typed localStorage utility that handles JSON serialization, deserialization, and error handling. On top of that, create a custom event bus so that when one component writes to storage, other components reading the same key re-render automatically. Expose this through a `useStorage` React hook with an API similar to `useState`.

**Acceptance Criteria**

- [ ] `src/lib/storage.ts` exports `getItem<T>(key, fallback): T`, `setItem<T>(key, value): void`, and `removeItem(key): void`
- [ ] All storage keys are prefixed with `dashboard-` to avoid collisions
- [ ] JSON parse errors are caught and return the fallback value
- [ ] A custom event bus (using `CustomEvent` on `window`) fires when any storage key is updated
- [ ] `src/hooks/use-storage.ts` exports `useStorage<T>(key, initialValue): [T, (value: T) => void]`
- [ ] `useStorage` subscribes to the custom event bus so cross-component sync works within the same tab
- [ ] `useStorage` also listens to the native `storage` event for cross-tab sync
- [ ] Unit-testable: storage functions are pure wrappers with no React dependency

**Files to Create or Modify**

- `src/lib/storage.ts`
- `src/hooks/use-storage.ts`

**Dependencies**

- Task 1 (project scaffolding)

**Estimated Scope:** Medium (2hr)
