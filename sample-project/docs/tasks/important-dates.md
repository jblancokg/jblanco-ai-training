# Important Dates Feature

Track birthdays, anniversaries, deadlines, and other significant dates with recurring support and a dashboard summary.

---

## Task 1: Define ImportantDate Type and Categories

**Description**

Create the TypeScript types for the important dates feature. Each date has a category (birthday, anniversary, holiday, deadline, other), an optional recurrence flag, and the core date information.

**Acceptance Criteria**

- [ ] `ImportantDate` interface at `src/features/important-dates/types.ts` includes: `id` (string), `title` (string), `date` (ISO date string, YYYY-MM-DD), `category` (DateCategory), `recurring` (boolean), `notes` (string, optional)
- [ ] `DateCategory` type defined as `"birthday" | "anniversary" | "holiday" | "deadline" | "other"`
- [ ] `CATEGORY_OPTIONS` array exported with label/value pairs for use in form selects and filter buttons
- [ ] All types are exported for use across the feature

**Files to Create or Modify**

- `src/features/important-dates/types.ts`

**Dependencies**

None.

**Estimated Scope:** Small (1hr)

## Task 2: Create Date Utility Functions

**Description**

Build a set of pure utility functions for working with important dates. These handle the logic for recurring dates (rolling the year forward so a birthday always shows the next occurrence), calculating days until a date, detecting "coming soon" dates, and identifying past non-recurring dates.

**Acceptance Criteria**

- [ ] `src/features/important-dates/date-utils.ts` exports the following functions:
- [ ] `getEffectiveDate(date: ImportantDate): Date` returns the next occurrence for recurring dates (rolls the year forward if this year's date has passed) or the original date for non-recurring ones
- [ ] `getDaysUntil(date: ImportantDate): number` returns the number of days from today until the effective date (negative if in the past)
- [ ] `formatDate(isoDate: string): string` returns a human-readable date string (e.g., "March 15, 2026")
- [ ] `isComingSoon(date: ImportantDate, withinDays?: number): boolean` returns true if the effective date is within the specified number of days (default 14)
- [ ] `isPastNonRecurring(date: ImportantDate): boolean` returns true if the date is non-recurring and has already passed
- [ ] All functions are pure with no side effects, making them straightforward to unit test

**Files to Create or Modify**

- `src/features/important-dates/date-utils.ts`

**Dependencies**

- Task 1 (types)

**Estimated Scope:** Medium (2hr)

## Task 3: Create useDates Hook

**Description**

Build the `useDates` hook that manages the list of important dates through the `useStorage` hook. It will expose the date list along with functions to add, update, and delete entries.

**Acceptance Criteria**

- [ ] `useDates` hook at `src/features/important-dates/use-dates.ts` returns `{ dates, addDate, updateDate, deleteDate }`
- [ ] `addDate(data)` creates a new date entry with a unique ID generated by `crypto.randomUUID()`
- [ ] `updateDate(id, data)` merges updated fields into the existing date entry
- [ ] `deleteDate(id)` removes the date from the list
- [ ] All state is persisted through `useStorage` under the key `important-dates`
- [ ] If storage is empty on first load, seed data from Task 4 is used as the initial value

**Files to Create or Modify**

- `src/features/important-dates/use-dates.ts`

**Dependencies**

- Dashboard Shell Task 4 (`useStorage` hook)
- Task 1 (types)
- Task 4 (seed data, can be a stub initially)

**Estimated Scope:** Small (1hr)
