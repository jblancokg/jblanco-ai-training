# Personal Dashboard

A browser-only personal dashboard for managing your day at a glance. Built with React 19, TypeScript, TanStack Router, Tailwind CSS v4, and shadcn/ui.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Available Commands

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start development server |
| `pnpm build` | Production build |
| `pnpm lint` | Run ESLint |
| `pnpm typecheck` | TypeScript type checking |

## Features

- **Todo List** - Track tasks with due dates, filtering, and sorting
- **World Clock** - Live clocks for 5 timezones with day/night indicators
- **Important Dates** - Track birthdays, deadlines, and anniversaries with countdown badges
- **Notepad** - Notepad widget with conversion to permanent full-page notes
- **Pomodoro Timer** - Timer widget to track focus states.
- **Habit Tracker** - Weekly habit tracker with a streak counter.

All data is stored in localStorage. No account or backend needed.
