# LaunchDarkly Features

## Core Feature Flags
- Boolean and multivariate feature flags
- User targeting with complex rules and segments
- Percentage-based rollouts
- Kill switches for instant rollback
- Flag prerequisites and dependencies
- Scheduled flag changes

## Experimentation
- Built-in A/B testing and experimentation
- Statistical analysis of feature impact
- Metric tracking tied to flag variations

## Compliance and Governance (Key for Banking)
- **Audit logging:** Complete audit trail of all flag changes ([LaunchDarkly Financial Services](https://launchdarkly.com/solutions/financial-services/), accessed 2026-02-27)
- **RBAC and custom roles:** Fine-grained access control (Enterprise+ plans)
- **Change approval workflows:** Require approvals before flag changes reach production
- **ServiceNow integration:** For change management compliance
- **SSO/SAML:** Enterprise authentication
- **Scoped API tokens:** Limit API access by project/environment

## SDK Support
Extensive SDK support across:
- Server-side: Node.js, Python, Java, Go, .NET, Ruby, PHP, Rust, and more
- Client-side: JavaScript, React, iOS, Android, Flutter, React Native
- Edge: Cloudflare Workers, Vercel

## Integrations
- CI/CD: GitHub, GitLab, Bitbucket, Jenkins
- Observability: Datadog, New Relic, Splunk, Honeycomb
- Collaboration: Slack, Microsoft Teams, Jira
- Change management: ServiceNow

## Deployment
- **Cloud-only** (SaaS) -- no self-hosted option
- US and EU regional instances
- No Canadian region available

## Strengths
- Most mature and feature-rich platform in the market
- Best-in-class targeting and segmentation
- Strong compliance feature set for regulated industries
- Largest ecosystem of integrations and SDKs
- Sub-millisecond evaluation latency at scale (trillions of evaluations daily)

## Gaps
- No self-hosted deployment option
- No Canadian data residency
- Complexity can be overwhelming for smaller teams
- UI criticized as clunky by some users ([G2 reviews](https://www.g2.com/products/launchdarkly/reviews), accessed 2026-02-27 -- 40 mentions of poor UI)
