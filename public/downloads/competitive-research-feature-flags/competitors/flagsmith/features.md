# Flagsmith Features

## Core Feature Flags
- Boolean and multivariate flags
- User targeting and segmentation
- Percentage rollouts
- Remote configuration (key-value pairs beyond boolean flags)
- Real-time flag synchronization (instant updates)

## Experimentation
- A/B testing capabilities
- Analytics integrations for measuring feature impact

## Compliance and Governance
- **Audit logging:** Full change history
- **RBAC:** Role-based access control
- **Flag change approvals:** Four-eyes principle support for regulated environments
- **SOC 2 Type 2:** Certified
- **Open source:** Codebase auditable by your own security team

## SDK Support
Broad SDK support:
- Server-side: Python, Java, .NET, Node.js, Ruby, Go, PHP, Rust
- Client-side: JavaScript, React, Angular, iOS, Android, Flutter, React Native
- Significantly more native integrations than Unleash ([Flagsmith vs Unleash comparison](https://www.flagsmith.com/compare/flagsmith-vs-unleash), accessed 2026-02-27)

## Integrations
- CI/CD: GitHub, GitLab, Bitbucket
- Observability and analytics: Datadog, New Relic, Amplitude, Segment, Mixpanel
- Collaboration: Slack, Jira

## Deployment Options (Key Differentiator)
- **Cloud SaaS** -- Flagsmith-hosted
- **Private Cloud** -- Dedicated instance managed by Flagsmith
- **Self-hosted (On-premises)** -- Run on your own infrastructure with full control
- Self-hosted version is free and open source with no usage limits ([Flagsmith self-hosted page](https://www.flagsmith.com/on-premises-and-private-cloud-hosting), accessed 2026-02-27)

## Strengths
- Most flexible deployment options in the market (SaaS, private cloud, self-hosted)
- Open source with no usage limits on self-hosted
- Explicit focus on regulated industries (banking, healthcare)
- Strong compliance feature set for a smaller vendor
- Real-time flag synchronization
- Growing positive reputation (4.8/5 on G2)

## Gaps
- Smaller company and community than LaunchDarkly or Unleash
- Fewer enterprise case studies publicly available
- Self-hosted requires ops investment
- Experimentation capabilities less mature than Split.io/Harness or LaunchDarkly
