# CloudBees Feature Management Features

## Core Feature Flags
- Boolean and multivariate flags
- User targeting and segmentation
- Percentage rollouts
- Kill switches
- Remote configuration

## Compliance and Governance (Key Strength)
- **Built-in OPA compliance policies** for SOC 2, PCI, FedRAMP, ISO 27001 ([CloudBees Compliance Features](https://www.cloudbees.com/capabilities/compliance/features), accessed 2026-02-27)
- **Auditor-dedicated view** with automatic evidence collection
- **DORA compliance** support for financial services
- **SOC 2 certified** ([CloudBees SOC 2 docs](https://docs.cloudbees.com/docs/cloudbees-feature-management/latest/security/soc-2-compliance), accessed 2026-02-27)
- **ISO 27001 certified** (CloudBees ISMS and Unify) ([CloudBees Trust Center](https://www.cloudbees.com/company/trust-center), accessed 2026-02-27)
- Audit logging and change tracking

## SDK Support
- Server-side and client-side SDKs available
- Specific SDK list available at [CloudBees FM documentation](https://docs.cloudbees.com/docs/cloudbees-feature-management/latest/), accessed 2026-02-27

## Integrations
- Deep integration with CloudBees CI/CD platform
- Jenkins ecosystem integration
- Supply chain monitoring and security testing (paid plans)

## Deployment
- Cloud SaaS primary
- Self-hosted availability unclear for feature management specifically [VERIFY]
- CloudBees broader platform has on-premises options

## Strengths
- Best-in-class built-in compliance tooling (OPA policies, auditor views)
- DORA compliance support for financial services
- Established enterprise vendor
- Unlimited server-side flags (cost-effective for backend-heavy architectures)
- Integrated with broader software delivery platform

## Gaps
- Feature management is secondary to CI/CD business -- may get less investment
- Pricing is opaque
- Smaller feature flag community
- Self-hosted options for FM module unclear
- May require broader CloudBees platform adoption
- Fewer third-party reviews ([TrustRadius](https://www.trustradius.com/products/cloudbees-feature-management/reviews), accessed 2026-02-27)
