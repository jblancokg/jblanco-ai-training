# Statsig Features

## Core Feature Flags
- Feature gates (boolean flags)
- Dynamic configs (multivariate/remote config)
- Percentage rollouts
- User targeting and segmentation
- Automatic rollback when health metrics degrade

## Experimentation (Key Strength)
- A/B testing with sequential testing
- Switchback testing
- Real-time health checks
- Automatic rollback on metric degradation
- Statistical rigor from Facebook-era experimentation platform

## Product Analytics
- Built-in analytics pipeline
- Metric tracking and dashboards
- Single data pipeline for flags + experiments + analytics

## Compliance and Governance
- SSO available on enterprise plans
- Audit logging [BASED ON TRAINING DATA - VERIFY]
- Compliance certifications not prominently documented on website

## SDK Support
- Server-side and client-side SDKs for major platforms
- Specific SDK inventory not verified in this research [VERIFY at statsig.com/docs]

## Deployment
- **Cloud SaaS** -- primary model
- **Warehouse-native** -- connect to your own data warehouse for data processing
- **No self-hosted option** for the application itself

## Strengths
- Most advanced experimentation and statistical testing
- Unified flags + experiments + analytics in single pipeline
- Usage-based pricing (no per-seat charges)
- Generous free tier
- Warehouse-native option for data control

## Gaps
- No self-hosted deployment -- deal-breaker for many banking use cases
- Compliance certifications not prominently marketed
- Younger company with less enterprise track record
- Not focused on regulated industry needs
- Warehouse-native partially addresses data residency but does not fully solve it
