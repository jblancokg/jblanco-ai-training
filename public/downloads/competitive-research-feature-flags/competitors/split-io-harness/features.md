# Split.io (Harness FME) Features

## Core Feature Flags
- Boolean and multivariate flags
- User targeting and segmentation
- Percentage rollouts
- Kill switches

## Experimentation (Key Differentiator)
- Treat every rollout as a controlled experiment
- Built-in A/B testing with statistical rigor
- Impact analysis and metric attribution
- Automatic alerting on metric degradation

## Compliance and Governance
- **Audit logging:** Full change history
- **SSO/SAML:** Enterprise authentication
- **SOC 2 Type II:** Certified ([Split.io Trust Center](https://www.split.io/trust/compliance/), accessed 2026-02-27)
- **ISO 27001, 27017, 27018:** Certified
- **Encryption:** Industry-standard data encryption at rest and in transit

## SDK Support
Server-side and client-side SDKs for major languages and frameworks. Specific SDK list available at [Harness Developer Hub](https://developer.harness.io/docs/feature-management-experimentation/getting-started/split-and-harness/), accessed 2026-02-27.

## Integrations
- CI/CD: Native integration with Harness CI/CD pipeline
- Observability: Integrations with monitoring tools
- Collaboration: Slack, Jira

## Deployment
- **Cloud-only** (SaaS) -- primary deployment model
- No documented self-hosted option for feature management specifically
- Harness broader platform has some on-premises capabilities [BASED ON TRAINING DATA - VERIFY]

## Strengths
- Best-in-class experimentation and statistical analysis
- Data-driven approach to feature delivery
- Part of comprehensive Harness software delivery platform
- Strong compliance certifications

## Gaps
